# 🗄️ إضافة إدارة التهجير (Migration Manager) لمنصة MYADS — v1.0.0

[![MYADS Compatibility](https://img.shields.io/badge/MYADS-4.5.6%2B-blue.svg)](https://github.com/mrghozzi)
[![PHP Version](https://img.shields.io/badge/PHP-8.2%2B-777BB4.svg)](https://php.net)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

إضافة **إدارة التهجير (Migration Manager)** هي أداة متقدمة لفحص وصيانة قاعدة البيانات في نظام **MYADS**. تتيح الإضافة للمدير فحص سلامة الجداول، تشغيل ملفات التهجير المعلقة بنقرة زر دون الحاجة للوصول إلى سطر الأوامر (SSH / Terminal)، واكتشاف السجلات المفقودة أو الجداول غير المنشأة.

---

## ✨ المميزات الرئيسية

1. **🔍 فحص سلامة وتناسق قاعدة البيانات**:
   - مؤشر مرئي يوضح حالة قاعدة البيانات (سليمة / غير سليمة).
   - إحصاء دقيق لعدد ملفات التهجير الإجمالية والمنفذة.
   - كشف الجداول المفقودة (Missing Tables) التي تم تعريفها في ملفات التهجير ولم تُنشأ فعلياً في قاعدة البيانات.

2. **⚡ تنفيذ ملفات التهجير الفردية (Pending Migrations)**:
   - مسح تلقائي لملفات التهجير في مسار النظام الأساسي `database/migrations` وكذلك مسارات الإضافات `plugins/*/database/migrations`.
   - إمكانية تشغيل أي ملف تهجير معلق بشكل مستقل ومباشر.

3. **👻 تنظيف سجلات التهجير الشبحية (Ghost Migrations)**:
   - رصد السجلات الموجودة في جدول `migrations` بقاعدة البيانات والتي حُذفت ملفاتها من السيرفر.
   - حذف السجلات الزائدة بنقرة زر واحدة للحفاظ على نظافة النظام.

4. **🛡️ أمان وسهولة استخدام**:
   - حماية كاملة عبر طبقات الحماية الافتراضية لمنصة MYADS للمدراء فقط (`admin` middleware).
   - اندماج كامل ومباشر في القائمة الجانبية للوحة التحكم.

---

## 📋 المتطلبات

- **منصة MYADS**: إصدار `v4.5.6` أو أحدث.
- **PHP**: إصدار `8.2` أو أحدث.
- **قاعدة البيانات**: MySQL 5.7+ أو MariaDB 10.3+.

---

## 🚀 طريقة التثبيت والاستخدام

1. ضع مجلد `migration-manager` داخل مجلد الإضافات `plugins/` في نظامك.
2. توجه إلى **لوحة الإدارة** ← **الإضافات (Plugins)**.
3. قم بتفعيل إضافة **Migration Manager**.
4. ستظهر الإضافة مباشرة في القائمة الجانبية باسم **إدارة التهجير (Migrations)**، أو يمكنك الدخول إليها عبر:
   ```text
   /admin/migration-manager
   ```
